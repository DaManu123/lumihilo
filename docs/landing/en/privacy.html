Privacy policy

Lumihilo · Last updated: November 10, 2026 · Español

In short: there are no accounts, no ads, and nothing from your games is sent to any server (the app only makes an anonymous check for a new version). Your progress lives only on your device.

1. Controller and contact

Lumihilo is developed and maintained by an independent developer. For any question or request about this policy, write to myprimemg@gmail.com.

2. Data we do not collect

  • No accounts or passwords: you do not need to sign up or give a name or email to play. (An email is only asked for if you choose to join the beta from the website; see section 9.)
  • No personal data: we do not ask for camera, microphone, location, contacts or storage.
  • No social features: there is no chat, forum or public player list.

3. What is stored and where

Your progress (level, Sparks, streak, statistics) and your settings (sound, music, vibration, theme, accessibility, language) are saved only on your device: in the app's preferences on Android, or in the browser's local storage in the web version. They are not synced or sent anywhere.

New-version notice. When it starts, the Android and desktop apps read the public list of published game versions (a file on damanu123.github.io, or the GitHub API as a fallback) to tell you if a newer one exists. It is a read-only request that includes no data about you or your games; GitHub may log technical data about the request, such as the IP address. You are asked once each time you open the app while a newer version exists, and you can keep playing without updating; you can also check manually in Settings. The web version does not make this request. When the game is distributed through Google Play, this check is replaced by Play's own updates and the app stops contacting GitHub. Updating without leaving the app (only the Android APK downloaded from GitHub). If you accept the update, the app downloads the new version's APK from the game's official Releases page on GitHub (GitHub may log technical data about the download, such as the IP address) and opens Android's installer, where you confirm the installation; Android only installs APKs signed with the same key as the app. Nothing about you or your games is sent. This does not exist in the Google Play version, which is updated through the store.

4. Ads and third-party services

The game contains no ads, no analytics tools and no third-party services that collect data.

If advertising or any other service that processes data is added in the future, this policy will be updated before that version is released, explaining what data is processed, why, and how to control it.

The web version is hosted on GitHub Pages, which may log technical visit data (such as the IP address) under GitHub's privacy statement.

5. Android permissions

The app uses the vibration permission, for the game's haptic feedback. The APK downloaded from GitHub also declares the permission to install apps, which is only used to install the update you accept (Android asks you to confirm it, and you can revoke the permission in its settings). The Google Play version does not declare it.

6. How to delete your data

  • Android: Settings > Apps > Lumihilo > Storage > Clear data, or uninstall the app.
  • Web: clear the site data in your browser.

7. Children

The game is intended for a general audience. We collect no data from anyone, and therefore none from children either. If you have any concerns, write to the contact email.

8. Changes to this policy

Any change will be published on this page with the date of the latest revision.

9. Optional beta sign-up (website)

If you ask to join the Google Play closed test from the presentation page, we receive only the email of your Google account (and, if you use the form, your consent).

  • Why: only to add you to the Play Console testers list and write to you about the test.
  • Who sees it: only the developer. It is not published, sold or shared with third parties, except with Google, which runs the Play testers list and, if used, the form.
  • How long: until the closed test ends; it is deleted afterwards.
  • Your rights: you can ask for access, correction or deletion at any time by writing to myprimemg@gmail.com.

This does not affect the game, which still collects no data.
