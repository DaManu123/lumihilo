# Lumihilo v0.1.0-beta.6

El juego ahora se llama **Lumihilo** (antes "Puzzle Adaptativo").

## Novedades
- Nuevo nombre en el juego, la app, los archivos de descarga y la web.
- Español e inglés: automático según el dispositivo o a elegir en Ajustes → Accesibilidad → Idioma.
- Accesibilidad: alto contraste, marcas de energía en las piezas encendidas y velocidad de animación.
- Versión web jugable y política de privacidad públicas.

## Para probar
- En Android, la app mantiene el mismo identificador, así que se actualiza sobre la beta.5.
- En Windows y Linux, el ejecutable cambia de nombre; tu progreso se conserva.
- Prueba el cambio de idioma y el alto contraste.
