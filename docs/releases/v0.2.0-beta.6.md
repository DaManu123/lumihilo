# Lumihilo v0.2.0-beta.6

## Novedades
- **Cambios internos para Google Play.** La fuente de las actualizaciones ya se decide al compilar: el APK de GitHub sigue avisándote de versiones nuevas, y el paquete para Google Play (`.aab`) no busca nada porque lo gestionará la tienda. No cambia nada en el juego.

## Para probar
- Se instala encima de la beta.5 y conserva tu progreso.
- Comprueba que, abriendo la beta.5, te ofrece actualizar a esta, y que **Ajustes → Buscar actualizaciones** sigue funcionando en esta versión.
- Esta versión sirve sobre todo para validar el flujo de publicación nuevo (el APK y el AAB salen con distinta fuente de actualizaciones).
