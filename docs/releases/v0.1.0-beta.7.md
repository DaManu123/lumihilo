# Lumihilo v0.1.0-beta.7

## Importante: desinstala la versión anterior
Esta beta usa el identificador definitivo de Android (`com.damanu.lumihilo`). **No se instala encima de la beta.6**: desinstala la anterior primero. El progreso guardado no se traslada.

En Windows y Linux la carpeta de datos pasa a llamarse `Lumihilo`, así que tampoco se conserva el progreso anterior.

## Cambios
- Identificador de Android definitivo, listo para Google Play.
- El repositorio ahora es https://github.com/DaManu123/lumihilo y la web está en https://damanu123.github.io/lumihilo/play/.
