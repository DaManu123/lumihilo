# Lumihilo v0.2.0-beta.4

## Novedades
- **Piedras en Luces.** Desde cierto nivel de habilidad aparecen casillas bloqueadas (una al principio, hasta cuatro): no se encienden, no se pueden tocar, no cambian cuando tocas a su vecina y no cuentan para ganar. Hay que rodearlas. Siguen siendo niveles con solución, y las pistas las tienen en cuenta. La primera vez sale un aviso breve que las explica, y el panel cuenta solo las casillas jugables.
- Incluye el aspecto **Aurora** de la beta.2. Esta versión **no** lleva el relleno de Chispas de la beta.3 (era solo una build de prueba).

## Para probar
- Se instala encima de la beta.2 o la beta.3 y conserva tu progreso.
- Si tienes la beta.3, tus Chispas se quedan como están (ya no se rellenan solas).
- Juega varios niveles de Luces con piedras: ¿se entiende que no se pueden tocar?, ¿el aviso aparece una sola vez?, ¿te parecen bien de difíciles?
- Para ver piedras necesitas haber jugado algunos niveles de Luces hasta subir de nivel de habilidad (empiezan en el nivel 3 de 8).
